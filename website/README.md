# LANX website

The download page for LANX, the office messenger that works on your own network. A static site:
open `index.html` in a browser, or host the folder anywhere (made for Vercel, served from this
folder of the LANX repository).

- **Publishing and updating:** see [DEPLOY.md](DEPLOY.md).
- **New LANX version:** from the LANAPPLICATION folder, `node website/update-website.mjs`, then commit and push `main`.
