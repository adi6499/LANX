# LANX — office messenger on your own network

**Download for Windows: https://lanx-website.vercel.app** · [direct download](https://lanx-website.vercel.app/download)

LANX lets the computers in an office chat, send files of any size, call each other and share updates —
on the office network, with no internet, no server and no accounts. Everything is end-to-end encrypted.

## Install or update
1. Download the installer from the page above and run it. Windows asks *"Do you want to allow this app to
   make changes?"* → **Yes**.
2. If a blue *"Windows protected your PC"* box appears (the installer is not code-signed): click
   **More info → Run anyway**.
3. LANX opens. Your chats and settings are kept when you update.

Colleagues who already have LANX 1.2 or newer get updates **through LANX itself**: on one PC open
**Settings → Updates**, choose the new installer and tick the colleagues — their LANX downloads and checks it,
and they click *Update now*.
